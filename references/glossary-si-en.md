# Glossary Sinhala ↔ English
| English | සිංහල |
|---|---|
| Income tax | ආදායම් බද්ද |
| Year of Assessment (Y/A) | තක්සේරු වර්ෂය |
| Taxable income | බදු ගෙවිය යුතු ආදායම |
| Assessable income | තක්සේරු කළ හැකි ආදායම |
| Personal relief | පුද්ගලික සහන |
| Tax return | ආදායම් බදු ප්‍රකාශය / return එක |
| TIN | බදු ගෙවන්නා හඳුනාගැනීමේ අංකය (TIN) |
| APIT (advance personal income tax) | වැටුපෙන් කපන අත්තිකාරම් පුද්ගලික ආදායම් බද්ද |
| AIT / WHT | අත්තිකාරම් ආදායම් බද්ද / රඳවා ගැනීමේ බද්ද |
| Instalment | වාරික ගෙවීම |
| Final payment | අවසාන ගෙවීම |
| Capital gains tax | ප්‍රාග්ධන ලාභ බද්ද |
| Inland Revenue Department | දේශීය ආදායම් දෙපාර්තමේන්තුව (IRD) |
| Penalty / interest | දඩ මුදල / පොලිය |
| Refund | බදු ආපසු ගෙවීම |
| Resident | ශ්‍රී ලංකාවේ පදිංචිකරු |

**FAQ phrasing**: "tax file එක දාන්න ඕනද?" → "ඔබට return එකක් ඉදිරිපත් කළ යුතුද?" · "tax එක කීයද?" → "ඔබ ගෙවිය යුතු බදු මුදල කොපමණද?"
